Source of truth: `designs/v1.5/One Down v1.5.dc.html` (+ `support.js` canvas runtime).

## 0. Saved theme (the colours the page actually shows)

The doc is themed via props (`data-props` tail of the HTML). Finn's saved defaults:

- `themeColor: #2C6E6A` (teal) — every **clay** tone re-hues to it (hue-shift by the delta from
  clay `#B0553A`, saturation × ratio of target/base saturation, lightness preserved)
- `screenTint: #E7EFEC` (cool mint) — every **ground** re-tints to it, saturation × **50%**,
  lightness **+5pts**
- `titleFont: Gabarito` (grotesque) — titles render Gabarito **500** (not Newsreader)
- `listClipMode: Soft fade` (scroll clip = gradient fade, not inset shadow)
- `swipeClip2d: 180ms`; `motion: true`; `softGradient: false`; `cardEditIcon: true`
- Sonar ripple (bonus halo): gold `#B98A32`, duration 7.5s, pause −4.8s, ease "fast then
  gentle", end width 70 / end blur 70, start width 0 / blur 3, alpha .36, max-opacity at 5% of
  cycle, fade at 25%; static glow: blur 9, spread 1, alpha .5, gold.

Gold, pine-green, blueprint-blue and the warm ink/muted greys NEVER re-theme — they carry
meaning (S·COLOUR: "Gold, pine and blueprint blue never move").

## 1. Type & form (S·TYPE & FORM)

- **Titles: Gabarito 500** (saved theme override of Newsreader) — card 31/36, screen 28,
  −1% tracking. Weight <500 in design → Gabarito 400.
- **Karla 400/500/600/700** — all UI text.
- **DM Mono 500** — every number, date, caps label; letter-spacing .07–.11em on caps.
- Radii: 22 card · 15–18 field/row · 11–13 chip · 999 pill. Warm-tinted shadows only.
- **Buttons, three weights:** filled 54px pill + shadow = the ONE terminal action per screen
  (Mark as complete, Brain dump, Save and next, Add N tasks, Done editing) · filled 40px
  radius-13, no shadow = strongest secondary (Get more steps) · plain text = ignorable
  (Change these, Cut it loose, Skip this one, Back to the dump). Small controls = primary ink
  on primary tint, radius 10–12 (Change, Edit, Undo chips).
- Fonts ship via `@expo-google-fonts/gabarito`, `/karla`, `/dm-mono` + `useFonts` (JS assets,
  OTA-safe; same pattern as current Nunito).

## 2. Meaning rules (S·WHAT THINGS MEAN)

- Solid ★ = stars you own; hollow ☆ = banked on an unfinished task. Applies to home counter
  (`★ 65 · ☆ 1 banked`), working header (`★ 20 when done · ☆ 4 banked`), and completed step
  rows (hollow star(s) per row). "+1 today" NEVER includes banked.
- Bonus = badge + reason on the card band; card keeps its own value (5/20) in a white pill at
  the other end. Lists keep badge + value, drop the reason. Badges expire; base never falls;
  two reasons never stack — larger badge wins.
- Dashes = provisional (triage cards + entry button, unconfirmed guesses, unguessable
  deadline). Blueprint blue travels with dashes = "we filled this in, you haven't agreed".
- Grey + dashed = nothing to guess ("NOTHING TO GO ON" / "Missing this detail").
- Gestures where you read (deck swipe, receipt row swipe-to-remove); visible controls where
  you edit (edit mode grips + bins).
- Block arrows (4-unit shaft, 11-unit head) in the label's own ink: right-pointing beside
  collapsed "Right now", turning down on the expanded sheet.

## 3. Star economy (Row E — REPLACES current weights)

- **Quick win = ★5. Big time = ★20.** Size alone sets value (pill counts up/down when size
  toggles on card back). Tasks pay in fives. (Unsized: see ambiguities — treated as quick win
  value until sized.)
- **Banking:** completing a step banks hollow stars — **1/step on quick win, 2/step on big
  time**; caps: 5 steps bank on a quick win, 10 on a big time (indicator fills exactly at card
  value; steps beyond the cap bank nothing). Un-ticking un-banks. **Completing the task
  converts the lot in one go** — completion award = card value + live badge − already-banked
  (ledger: banked rows stay, completion row = remainder), so the task total always equals
  value + badge.
- **Bonus window (deadline):** opens 4 days before deadline, runs 2 days (gone from 2 days
  out). Badge **+3 quick / +10 big**, reason `BONUS UNTIL <weekday>` (the day the window
  closes). Short notice (<4 days lead): opens immediately, runs 2 days capped at deadline.
  Offered once per deadline. Card chrome: gold band (`#F7EBD2`/`#E7D3A6`), `+N` chip
  (`#F1DEB0`), white value pill, `#DEC48A` card border, gold rail `#FDF6E7`, gold due-line,
  halo (static glow) + sonar ripple per saved settings.
- **From 2 days out:** no badge; clay band `TOP OF THE DECK` (`#E1F5F5` themed bg, `#BDE1E1`
  border, primary-ink label), card border = primary line, due line primary ink `Due in 2
  days`; the card is dealt FIRST in the deck (curation override), still subject to filters —
  the dot (below) marks it when filtered out.
- **Don't-skip offer:** triggers by avoidance (3 passes of the top card) or age (stale ≥7d,
  avoidance fires first); a coin flip when the card next comes round decides IF it appears;
  amount fixed by size: +3 quick / +10 big, reason `TO START IT NOW`, same gold chrome as the
  window. Erosion per committed pass: quick 3·1·0, big 10·6·2·0. During the drag the badge
  shows the next value and a clay `−2`/`−4` rises from the badge and fades as the card leaves;
  snap back = retraction. At 0 the offer is spent; can re-offer after ~3 days. **One live
  offer at a time** (globally). Larger badge wins if window + offer both qualify.
- **Urgency dots:** 10px primary dot (2px paper ring) on UNSELECTED context chips hiding a
  live bonus or overdue card; collapsed bar → dot rides on `Change`. One dot per tile, no
  counts.
- **Triage pay:** per-card confirms pay nothing; **emptying the triage queue = +5, max once
  per day** (`CLEAR THE QUEUE · ★ 5` header line).
- Cut loose stays +3 (not addressed by design — kept). Spending/prices (flourish 150 · theme
  400 · mechanic 1000) are FUTURE — not implemented; single counter stays.
- List rows carry badge + value (`+3` chip + `5★`), bonus rows warm-tinted (`#FFFCF4` /
  `#EEDDB0`).

- **Keyboard (05f):** notes focused → title/desc stay; step list becomes its own scroll area,

  exactly. Everywhere else the keyboard overlays without relayout.
- **Edit mode (05a/05b):** label line `✏ EDITING N STEPS` + `Done` chip; rows same
  size/radius; grip 17px left, bin 16px right; done rows `#FBF7F0`-equivalent bg; drag from
  the grip lifts (shadow, −1.4° tilt, offset) over a dashed primary slot; `Add a step` dashed
  row; hint `Drag to reorder · tap the words to rewrite`; tap words = caret in place,
  keyboard up, row gets primary border + trailing check, return commits; edits apply
  immediately; delete = tap bin + undo toast; notes + terminal at 62% opacity.
- **Change these (05c–05e):** dashed primary box `WHAT SHOULD BE DIFFERENT` + free text;

- **Get more steps:** requests three more steps; if the list already finishes the task, the

- **Completion (~560ms):** toast pill (dark) — gold ★ 21px pulsing 1→1.12 (45% keyframe),

## 7. Brain dump (Row C) — becomes a gated check flow

- **07 input:** serif→Gabarito title `Brain dump`, sub `Get it all out, any format — we'll
  sort it into tasks.`; large surface textarea; gold-star hint line `Add all the details,
  timings or difficulties you can think of. All context is good context`; primary
  `Parse my tasks`; text `Add one task instead`.
- **07f check screen (`Check these N`):** NOTHING saved until `Add N tasks` is pressed.
  A box per task: pine check glyph + title (Karla 600 14.5) + edit affordance; evidence
  quotes indented under (left rule, faint); tap title to reword (inline caret); **×** on the
  row drops the task; swipe a row = remove (same gesture as deck). Unclaimed lines: primary
  (clay→teal) dashed tinted rows with quote rule + **+** button — promotes via AI (writes it
  a title, becomes an ordinary box). List opens scrolled to the bottom (unclaimed lines are
  the loudest thing); soft-fade clip at the top; footer `Change these` text button +
  `N ENTRIES NOT ADDED` caps; primary `Add N tasks` + check; text `Back to the dump`.
- **07g/07h change flow:** dashed box `WHAT SHOULD BE DIFFERENT`, placeholder `Describe a
  split, a merge, or something we missed`; re-parses the WHOLE dump with the feedback —
  tasks can merge/split/gain evidence; promoted-by-change evidence lines carry a primary
  rule; counts move (`Check these 7`, button `Add 7 tasks`).
- **Server contract:** parse returns per-task `evidence: string[]` + top-level
  `unclaimed: string[]`; re-parse accepts prior dump + feedback; promote-line accepts one
  line. Review flags/WE GUESSED still generated as today.
